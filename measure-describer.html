Step1

Export your model from Power BI Desktop

This is the same query the KPI Measure Builder uses. If you already ran it, paste those results in Step 2.

  1. Open your report in Power BI Desktop and select DAX query view on the left rail.
  2. Paste the query below into a new query tab and select Run.
  3. Above the results grid, select Copy. It copies every row with the column headers.
