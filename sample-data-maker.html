What each choice does
  • Fake ID: digits and letters are swapped, the shape and any shared start (such as CUST-) stay. Each ID gets its own fake one.
  • Person name, Company name, City, Street address, Phone: made-up values. The same original always gets the same fake value, in every file.
  • Email: built from the fake person name in the same row when there is one, at example.com.
  • Numbered labels: each different value becomes the column name and a number, such as Product 12.
  • Scale numbers: the whole column is multiplied by a hidden factor, with a little noise per value, so totals and trends keep their shape. Totals that should add up across columns won’t exactly.
  • Shift dates: every date in every file moves by the same hidden number of whole weeks, so weekdays, gaps and seasons stay true.
