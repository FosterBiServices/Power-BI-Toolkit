Model Linter

Best-practice checks on your model export: measures without a folder or format string, visible key columns, bidirectional relationships, implicit measures, unused columns and measures, and, with a PBIP folder, report checks such as alt text and crowded pages. Each finding says why it matters and how to fix it in Power BI Desktop. No AI needed.

Report pages (optional)

          

        
Connected with a PBIP folder above? Its report pages are read from it too, so there’s nothing to add here. Otherwise, choose the project folder (or its .Report folder) of a report saved as a Power BI Project. Visible columns and every measure are then checked against each visual, filter, formatting rule and bookmark in it, and the report checks run: alt text, titles, hidden visuals, unused bookmarks, empty and crowded pages. If the folder also holds the semantic model, its field parameters are read so measures used only there count as used. If the folder holds several projects, you pick which reports to check, and each is read with its own semantic model. Files are read on this page; nothing is uploaded.
