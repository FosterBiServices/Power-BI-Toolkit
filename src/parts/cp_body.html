3. Update your report theme (required for this pattern)

          
This chart needs a change to your report theme. Power BI’s default marker is too small to hold a label, so without this step the bubbles show as small dots. The size is set in the theme, so this changes only line and clustered column charts.

          
    
            
  1. In Power BI Desktop, select View > Themes (the dropdown arrow) > Save current theme, and save the .json file.
    2. 
            
  2. Select Open your theme file below and pick that file. 
    3. 
            
  3. Check the bubble size in Step 4 (now ), then select  The page adds the marker size and keeps everything else in your file.
    4. 
            
  4. In Power BI Desktop, select View > Themes > Browse for themes and pick the downloaded file.
    5. 
          

          

          
Made your theme in Theme Builder? Set Combo chart bubble size in its Step 2, download it again and import that instead.

          
Prefer to edit the theme file yourself?

            
    
              
  1. Save the current theme as above and open it in Notepad.
    2. 
              
  2. Find "visualStyles". Inside it, look for "lineClusteredColumnComboChart".
    3. 
              
  3. If it’s not there, add this inside "visualStyles", with a comma after the entry before it:
                
    JSON
    4. 
              
  4. If it is there, don’t add a second one: a second copy replaces the first and drops its settings. Inside its "*": { ... }, add "lineStyles": [ { "markerSize":  } ] with a comma before it. If "lineStyles" is already there, add "markerSize":  inside its { } instead.
    5. 
              
  5. Save the file, then View > Themes > Browse for themes and pick it.
    6. 
            

          

          
Don’t set a marker size on the chart in the Format pane afterwards: a size set on the chart overrides the theme. If you import a different theme later, do this again.
