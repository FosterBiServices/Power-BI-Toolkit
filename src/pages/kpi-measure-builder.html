Step1

Export your model from Power BI Desktop

One query lists every table, column, relationship and existing measure. It uses the built-in DAX query view, so no extra tools are needed.

  1. Open your report in Power BI Desktop.
  2. Select DAX query view on the left rail. It's the icon below Model view.
  3. Paste the query below into a new query tab and select Run.
  4. Above the results grid, select Copy. It copies every row with the column headers.
DAX query

      

      
Also works in the Power BI service: open the semantic model and choose Write DAX queries (needs write permission on the model). Auto date/time tables and row-number columns are dropped automatically.

Step3

    

      

        
Describe the measures

        
One measure per line, in plain English. Mention the grain or filter if it matters, for example "excluding returns" or "for the selected fiscal year".

      

      
      
Copilot sees names, not data. It knows a column called [Segment] exists, not that its values are Consumer and Corporate. When a measure filters on specific values, name them in the request (“Sales for each customer Segment: Consumer, Corporate, Home Office”) or load them under Column values below.


      

        
Detailed measures

        
      

      
For measures a single line can't describe: ones that loop over rows (SUMX, MAXX), use a different date window for each row, or reach across several tables. The page works out how the tables connect and tells Copilot.

      


      

        Column values (optional)
        

          
For measures that filter on specific values. List the columns, run the query in DAX query view, and paste the results. The values go into the prompt so Copilot can write one measure per value and spell them exactly.

          Prompt for Copilot
          
        

        

      

      
Paste the prompt into Copilot. It's asked to answer inside one code block, in labeled blocks that need no escaping. The prompt always ends with === END OF PROMPT ===; long existing formulas are shortened on purpose and marked [formula shortened]. If Copilot's input box doesn't show the end line after pasting, the prompt is too long: clear tables you don't need or turn off existing formulas.
