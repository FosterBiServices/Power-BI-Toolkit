Get every query from your model

          
The Power Query code behind every loaded table, plus queries that aren’t loaded, functions and parameters. Read it from a PBIP folder, or run one DAX query in Power BI Desktop.

For a report saved as a Power BI Project (File > Save as > Power BI project files). Choose the project folder or its .SemanticModel folder. The queries are read from the model’s TMDL files, or from model.bim in older projects. Files are read on this page; nothing is uploaded.
