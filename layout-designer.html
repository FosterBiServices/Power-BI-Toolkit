Step3

Layout and visuals

Answer a few questions to get suggested layouts, or start from one of the layouts below. Then click any visual to change it, or an empty cell to add one. Visuals can span several columns and rows, and columns and rows can be any size.

Suggest a layout (3-30-300: list your visuals, get layouts sized for them)

A good report page answers three questions in order. 3 seconds: how are we doing? (headline KPIs top left, big numbers, status against target). 30 seconds: where and why? (trend, bar charts, maps, heatmaps, filters). 300 seconds: which records? (details on demand: a formatted table, or a drill-through page so this page stays clean).

3 s: headline numbers
30 s: your visuals

For each one: how many categories it has (bars, lines, slices, rows), and how many to show before a scroll bar. Sizes follow from these.

300 s: details

Build it row by row (each row with its own visuals and widths)

Each row splits the full width its own way. Type a height in px to fix a row (the others share what’s left). Click a visual on the page to change its type or title, or to split it into smaller boxes (a cluster of cards); empty cells become visuals here.

Column widths and row heights

Type a size in px to fix a column or row: it keeps that size and the others share what’s left. Empty the box (or ×) to let it resize. Or drag the handles between columns and rows on the page. Margin and gap stay the same; sizes snap to twelfths (hold Shift for any size).

Step4

Wireframe and files

Share the wireframe, and use the background image and positions in Power BI Desktop.

Wireframe with sample visuals

Background image

In Power BI Desktop: Format page > Canvas background > Image, Image fit: Fit, Transparency 0%. Then turn off each visual’s own background so the cards show through. The PNG is the page size you set in Step 1. PNG at 2× is twice that, for extra sharpness.

PowerPoint

Three slides at the page’s size: the layout as editable shapes (header, logo, title, cards and labels you can move, resize and recolor, with your shadow), the wireframe with sample visuals, and the background image. Good for design reviews and sign-off.

Into Figma

  1. Copy for Figma, then in Figma select a page and press Ctrl+V. The drawing arrives as one frame of editable shapes, with layers named Page, Header, Side-panel and Card-<visual>. Your logo and header image come along as images.
  2. Refine it there (shapes, icons, gradients). Shadows come through as SVG filters; if one doesn’t, add a Drop shadow effect with the same X, Y, Blur, Spread, color and opacity as in Step 2. Hide the sample visuals layer before exporting the background.
  3. Export the background frame as PNG at 1× (the page size) and set it as the canvas background in Power BI Desktop, as above.

Positions (Format pane > General > Properties: Size and Position)

Rename any visual in the first column: the new name goes into the wireframe, the PowerPoint and Figma layers, and the positions you copy.

Inner X, Y, width and height: where to put a visual so it stays inside its card, clear of the rounded corners. Use them when the visual keeps its own background or border; with the visual’s background off, the outer position works too.
