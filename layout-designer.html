Wireframe with sample visuals

Background image

In Power BI Desktop: Format page > Canvas background > Image, Image fit: Fit, Transparency 0%. Then turn off each visual’s own background so the cards show through. The PNG is twice the page size so it stays sharp.

Into Figma

  1. Copy for Figma, then in Figma select a page and press Ctrl+V. The drawing arrives as one frame of editable shapes, with layers named Page, Header, Side-panel and Card-<visual>.
  2. Refine it there (shapes, icons, gradients). Hide the sample visuals layer before exporting the background.
  3. Export the background frame as PNG at 2× and set it as the canvas background in Power BI Desktop, as above.
