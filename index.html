Step1

Export your model from Power BI Desktop

One DAX query lists the model’s tables, columns, measures (with their formulas and descriptions) and relationships. It reads the model’s definition only, not your data.

  1. Open your report in Power BI Desktop and select DAX query view on the left rail.
  2. Paste the query below into a new query tab and select Run.
  3. Above the results grid, select Copy. It copies every row with the column headers.

Good to know

    
    
      
  • Nothing leaves your browser. The pages don’t send data anywhere. Prompts only reach Copilot when you paste them yourself.
    • 
      
  • Where the export is kept: in this browser’s storage for this site, so it’s there next time on this computer, but not on another computer or in another browser.
    • 
      
  • One export at a time. Pasting a model export into any tool also replaces the saved one, so every tool stays on the same model.
    • 
      
  • Each tool keeps its own work (requests, replies, settings). Its Clear entries button empties that tool only, and the saved export stays until you remove it here. To empty every tool and remove the saved export at once, choose Clear all pages there or below.
    • 
      
  • The Power Query Explainer reads Power Query code, so its whole-model mode has its own export query. The Date Table Generator fills its date-column list from the saved export.
    • 
      
  • The Model Documenter uses the saved export for a quick document, or reads a PBIP project folder in the browser for the full one (Power Query, sources and report pages). The folder’s files are read on the page and never uploaded.
    • 
    

  


  

    
Disclaimer: use at your own risk

    
    
      
  • AI can make mistakes. Copilot replies can be wrong, incomplete or out of date, and can refer to tables, columns or measures that don’t exist. The pages check what they can (names, syntax, some results), but they can’t catch every error in logic or meaning. Read every reply before you use it.
    • 
      
  • Check all of the work. Everything the toolkit produces, with or without AI (DAX, Power Query, TMDL scripts, descriptions, themes, documents and lint findings), is a starting point to review, not a finished answer. Confirm results against figures you trust before anyone relies on them.
    • 
      
  • Test on a copy first. Scripts can add, replace or change objects in your model. Back up the report or keep it under version control (PBIP and Git), and apply changes to a copy before a production model.
