Power BI toolkit

SF Power BI Toolkit

Tools for building and checking Power BI models, with or without Copilot. Export your model once below and every tool that needs it picks it up.

Step1

Export your model from Power BI Desktop

One DAX query lists the model’s tables, columns, measures (with their formulas and descriptions) and relationships. It reads the model’s definition only, not your data.

  1. Open your report in Power BI Desktop and select DAX query view on the left rail.
  2. Paste the query below into a new query tab and select Run.
  3. Above the results grid, select Copy. It copies every row with the column headers.
DAX query: model export

      

      
Tip: rename the query tab to Toolkit export and keep it. DAX query view saves it in the file, so next time you only select Run and Copy.

The tools

    
Tools marked Uses your export load the saved export as they open. Tools marked Copilot write a prompt you paste into Copilot, then check its reply.

    

  


  

    
Good to know

    
    
      
  • Nothing leaves your browser. The pages don’t send data anywhere. Prompts only reach Copilot when you paste them yourself.
    • 
      
  • Where the export is kept: in this browser’s storage for this site, so it’s there next time on this computer, but not on another computer or in another browser.
    • 
      
  • One export at a time. Pasting a model export into any tool also replaces the saved one, so every tool stays on the same model.
    • 
      
  • Each tool keeps its own work (requests, replies, settings). Its Clear entries button empties that tool only; the saved export stays until you remove it here.
    • 
      
  • The Power Query Explainer reads Power Query code, so its whole-model mode has its own export query. The Date Table Generator fills its date-column list from the saved export.
    • 
    

  


  
Everything runs in this page. Your model export is saved only in this browser.
